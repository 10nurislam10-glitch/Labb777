# Командалық жоба (Лаб. жұмыс № 7)

GitHub-та бірлескен жұмыс: тармақтар (branch), коммиттер, Pull Request, Code Review, merge.

## Файлдар
- `index.html` — басты бет (барлық қатысушыларға сілтемелер)
- `student1.html` — 1-қатысушы (топ жетекшісі)
- `student2.html` — 2-қатысушы
- `style.css` — ортақ стиль

## Жұмыс тәртібі
1. `master` тармағына тікелей коммит жасамаймыз.
2. Әр өзгеріс — бөлек тармақта (`feature-...`).
3. Өзгеріс Pull Request арқылы, топ жетекшісінің тексеруімен енгізіледі.
4. Біріктірілген тармақ жойылады.

## Жұмыс тәртібі

1. Репозиторийді fork жасау.
2. Өз тармағын (branch) құру.
3. Өзгерістерді commit жасау.
4. Pull Request жіберу.
5. Топ жетекшісі тексеріп, біріктіреді.
